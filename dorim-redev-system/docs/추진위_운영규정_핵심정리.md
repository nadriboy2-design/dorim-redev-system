## 1. 회의 운영 — 양식에 반영해야 할 규정 (운영규정 별표)

### 추진위원회 회의
- **소집(제24조)**: 위원장이 필요 시. 아래 청구가 있으면 **14일 이내 소집 의무** — 토지등소유자 1/10 이상, 재적위원 1/3 이상. 위원장이 안 하면 감사가, 감사도 안 하면 청구자 공동명의로 소집.
- **통지**: 개최 **7일 전까지** 목적·안건·일시·장소를 적은 통지서를 위원에게 송부 **+ 게시판 게시**. 긴급 시 **3일 전** 통지 가능(출석위원 2/3 이상 찬성으로 의결).
- **통지한 안건만 의결(제25조②)**. 위원은 자신과 관련된 해임·계약·소송 **의결권 없음(제25조③)**.
- **의결(제26조)**: 재적위원 **과반수 출석**, 출석위원 **과반수 찬성**. (주민총회 갈음 사항은 재적 2/3 출석·출석 2/3 찬성)
- **대리 출석 불가, 서면 출석·의결은 가능(제26조②)**. 서면 출석은 출석으로 인정.
- **감사는 재적위원에 포함되나 의결권 없음(제26조③)**.
- 의장은 위원장(제17조①). 위원장 유고·자기 관련 계약/소송·해임 건은 부위원장·추진위원 중 연장자 순.
- 의결사항(제25조): 위원(위원장·감사 제외) 보궐선임, 예산·결산 승인 방법, 주민총회 부의안건 사전심의, 주민총회 의결 예산 범위 내 용역계약, 기타 운영 필요사항.

### 주민총회
- **구성(제20조)**: 토지등소유자 전원. 청구 시 **2개월 이내 개최** — 토지등소유자 1/5 이상 또는 추진위원 2/3 이상.
- **개최·일시 변경은 사전에 추진위 의결(제20조④)**.
- **통지**: 개최 **14일 전부터 게시판 게시**, **10일 전까지 등기우편 발송**(반송 시 1회 추가 발송). **통지한 안건만 의결(제20조⑥)**.
- **의결(제22조)**: 추진위 구성 **동의자 과반수 출석**, 출석자 과반수 찬성. **서면 결의는 전일까지 도착**해야 하며 출석으로 봄. 대리인 출석은 **위임장 + 관계 증명서류**.
- 정족수 미달 시 재소집, 재소집도 미달이면 추진위 회의로 갈음(이때 재적 2/3 출석·출석 2/3 찬성).
- 주민총회 의결사항(제21조): 위원장·감사 선임·변경, 운영규정 변경, 정비사업전문관리업자·설계자 선정·변경, 개략 사업시행계획서 변경, 감사인 선정 등.
- **대리 가능자(제13조②)**: 배우자·직계존비속·형제자매 중 성년자(위임장), 해외거주자의 대리인, 법인의 대리인. 공유자는 **대표소유자 선임동의서**.

### 회의록·공개 (제35조)
- **추진위원회·주민총회 의사록**은 공개 대상 서류(제35조①3). 작성·변경 후 **15일 이내** 인터넷 등으로 공개(주민등록번호 제외), 열람·복사 요청 시 **15일 이내** 응해야 함(실비 청구인 부담, **서면 요청**).
- **매 분기 종료 다음 달 15일까지** 공개 대상 목록·내용·장소·열람방법·비용을 서면 통지(제35조④).
- 주민총회·추진위 개최 시 서류와 **속기록·녹음·영상자료**를 만들어 조합설립인가일부터 **30일 이내** 조합에 인계(제35조②).
- 지출내역서는 분기별 게시, 결산보고서는 회계연도 종료 후 30일 내(제31조).
- 일반 공개·통지(제9조): 등기우편 개별통지 + 게시판 공고 + 홈페이지 병행, 발송·공고일부터 통지된 것으로 봄.

## 2. 고시 본문(제2026-15호) 요지
- 추진위 구성: 위원장·감사 포함 **5인 이상** + 운영규정안에 대한 토지등소유자 **과반수 동의** → 구청장 승인(제2조①). 위원 수 ≥ 토지등소유자의 1/10(50인 이하는 5인, 100인 초과 시 1/10 범위 내 100인 이상 가능).
- 위원 결격(제2조③): 미성년·후견, 파산 미복권, 금고 이상 실형 종료 후 2년 미경과, 집유 중, 법 위반 벌금 100만원 이상 후 5년 미경과 (※ 생활법령은 법 제33조·제43조 기준 **10년**으로 안내 → 법이 우선, 확인 필요).
- 승인 후 **위원장·감사 변경은 구청장 승인**, 그 외 변경은 **신고**(제4조②).
- 해산(제5조): 조합설립인가일까지 수행, 중도해산은 동의자 2/3 또는 토지등소유자 과반수 동의 후 신고. **업무범위 초과 계약·용역은 조합에 승계되지 않음(제6조)**.
- 구성동의는 시행규칙 별지 제4호서식에 운영규정안을 첨부해 징구(제2조④).

## 3. 절차·요건 (생활법령, 2026.9.15. 기준 / 조문은 도시정비법)

| 단계 | 요건·기한 | 조문 |
|---|---|---|
| 정비구역 지정 | 지방도시계획위원회 심의 후 지정·고시 | **제16조** |
| 추진위 승인 | 토지등소유자 **과반수 동의** + 구청장 승인. 동의자는 조합설립에도 동의한 것으로 봄(조합설립 인가 신청 전 반대 의사표시 시 제외) | 제31조 |
| 추진위 업무 | 정비업자·설계자 선정, 개략 사업시행계획서, 조합설립 준비, 정관 초안, 동의서 접수, 창립총회. 토지등소유자 비용부담·권리의무 변동 업무는 **사전 동의** 필요 | 제32조 |
| 조합설립인가 | 토지등소유자 **3/4 이상 + 토지면적 1/2 이상** 동의. 동의 전 분담금 추산액 정보 제공 | 제35조 |
| 시공자 선정 | **조합설립인가 후** 조합총회, 일반·지명경쟁 (2회 이상 유찰 시 수의계약 가능) | 제29조④ |
| 사업시행계획인가 | 총회 의결(사업비 10% 이상 증가 시 2/3 찬성), 인가권자 60일 내 결정 | 제45조, 제50조 |
| 관리처분계획인가 | 30일 이상 주민공람, 총회 의결, 인가 30일 내(타당성 검증 시 60일) | 제74조, 제78조 |
| 분양공고 | 사업시행인가 고시일(또는 시공자 계약일)부터 기한 내 통지·공고. **기한은 개정 중(120일→90일, 서울시 2025.7 조례 개정 안내)** → 확정 전 최신 확인 | 제72조 |

- **해제 위험 기한(제20조)**: 정비구역 지정·고시일부터 **2년 내 추진위 승인 신청**, 추진위 승인일부터 **2년 내 조합설립인가 신청**, 조합설립인가일부터 **3년 내 사업시행계획인가 신청** — 미이행 시 구역 해제 가능. 해제되면 추진위 승인·조합설립인가는 취소된 것으로 봄.
- 토지등소유자 30% 이상 해제 요청(추진위 미구성 구역), 추진위·조합 구역은 동의자 1/2~2/3 범위 내 조례 비율 또는 토지등소유자 과반수 동의로 해제 요청 가능(사업시행인가 신청 전).
- 추진위원장 직무 불능 6개월 이상 시 전문조합관리인 선정 가능(제41조⑤).

## 4. 서울시 2025 정책 (2025.7.3. 슬라이드)
- **2025.6.4. 도시정비법 개정 (일부 2025.12.4. 시행)**
  - **정비구역 지정 전에도 추진위 구성 가능**(입안 결정 지역 등, 법 제31조제2항제2호).
  - **동의 특례(제36조의3)**: 입안요청·입안제안 동의서로 추진위 구성 동의 갈음 가능(일정 요건 충족 시) → 동의 3차례→2차례(재개발), 재건축은 1차례. 요건: 다른 동의로도 인정될 수 있음을 고지, 인허가 신청 전까지 철회하지 않을 것, 철회·반대의사 절차 설명. 동의서 명칭 **입안동의서 → 정비구역 지정 동의서**.
  - **전자투표(법 제45조, 2025.6.4.)·온라인총회(법 제44조의2, 2025.12.4.)·전자동의서(법 제36조)** 도입.
- **선심의제**: 재개발 입안 동의율 **50% 확보 시점을 정비구역 지정 요청 전까지로 변경**(입안 전→지정 전, 6개월 이상 단축 가능). 슬라이드상 입안 요청 단계는 30% 동의.
- **처리기한제**: 입안요청→정비구역 지정고시 요청까지 재개발 단계별 기한(구청 2개월, 시 3개월 등).
- **공공지원**: 정비구역 지정 전 추진위 구성 시 보조금 교부 시점 규정. 조합직접설립 보조금 교부 기준 **주민동의율 75%→50% 완화**, 1·2차 분할 교부, 전자투표·전자동의서 도입.
- **조례 개정 안내(2025.7)**: 분양공고 기한 120일→90일(재개발 1만㎡ 이상은 30일 연장 가능), 감정평가법인 선정 기준 강화.
- ⚠ 프로젝트 CLAUDE.md의 "정비구역 입안 사전검토 40% 이상(역세권 운영기준 2026.3.6. 개정)"은 이 슬라이드(2025.7)에 없음 → 별도 기준으로 유지하되 일반 재개발 선심의제(50%)와 구분해 표기.

## 5. 질의회신 사례집 추진위 편(인쇄 p.103~117) 요지
- 추진위원 수: 운영규정 제2조②3호 기준, 구체 사항은 구청 문의(주거정비과-1049호, 2021.1.21.).
- **추진위 동의자는 구성·승인 후 동의 철회 불가**, 조합설립 반대는 **조합설립인가 신청 전**에 구청·추진위에 반대 의사표시(주거정비과-15107호, 2023.10.6.). 동의 철회·반대 시기: 인허가 신청 전까지, 일부 동의는 최초 동의일부터 30일.
- 비용부담·권리의무 변동 업무의 동의는 **서면동의서에 성명·지장 + 신분증 사본**(법 제36조①7호 인용, 주거정비과-10852호). 시행령 위임 비율 미규정 → 국토부 문의 안내.
- 위원 임기 만료 시 후임 선임은 만료 전 2개월 이내, 미선임 시 토지등소유자 1/5 이상이 구청장 승인으로 주민총회 소집. 위원 보궐선임은 추진위에서 **재적과반 출석·출석 2/3 찬성**, **위원장·감사 보궐선임은 주민총회 의결**(운영규정 제15조).
- 주민총회 정족수 미달 시 재소집 → 재소집도 미달 시 추진위 회의로 갈음(주거정비과-19009호).
- 감사: 토지등소유자 1/5 요청 시 공인회계사 회계감사 의뢰, 부정 발견 시 위원장에게 추진위 소집 요구(안 열면 직접 소집), 감사위원회 구성 가능(주거정비과-19127호).
- 서울시 공공지원: 추진위 구성 업무, 선거관리 위탁(법 제118조, 서울시 조례 제76조, 「공공관리 추진위원회 구성 선거관리기준」).
- 사례집 나머지(시공사·총회·조합원 자격 등)는 원본 PDF(서울특별시 도시정비법령 질의회신 사례집 2024)에서 필요 시 검색.
