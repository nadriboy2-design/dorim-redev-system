# 창원 대동백화점 부지 — 현장조사 체크리스트 (2026-11-11 작성)

> 목적: 단일부지(대동아파트부지) 중 백화점 부지만 분할 개발 시 사업성·리스크 팩트체크. 제안자에게 보여줄 근거 확보.
> 원칙: 현장에서 본 것은 **확인(현장)** 라벨, 사진·시각 병기. 제안서 수치는 **호가** 취급. 확인 못 한 것은 **미확인**.
> 아래는 "확인할 가설"이며 사실 단정이 아님. 자료(제안서·등기·대장) 수령 후 가설 검증/삭제.

## A. 분할 리스크 (핵심 쟁점)
- [ ] 분할 대상이 별도 필지인가, 한 필지 안의 일부인가 → 분할(분필) 가능 여부, 분할 후 각 필지 최소 면적·도로 접면
- [ ] 건축법상 대지분할 제한(§57), 분할 후 잔여 필지(아파트측)의 건폐율·용적률·주차·조경 등 법정기준 충족 여부
- [ ] 백화점·아파트가 **공용(주차장, 진입로, 설비, 지하층)** 을 공유하는가 — 현장에서 지하주차장 연결, 출입구, 기계실, 옥상 설비 확인
- [ ] 아파트 입주민 동의/공유지분·대지권 문제 (집합건물이면 대지권 비율, 구분소유 여부)
- [ ] 분할 선 위치에 건물 외벽이 걸쳐 있는지 (사진)

## B. 권리·점유
- [ ] 등기부: 근저당·가압류·신탁·지분 구조 (열람일 병기)
- [ ] 백화점 건물 현재 운영/폐업 여부, 잔여 임차인, 대항력, 권리금, 명도 난이도
- [ ] 건물 철거 시 석면·지하구조물 흔적(건물 연식, 지하층 수)

## C. 공법·인허가
- [ ] 토지이음: 용도지역/지구, 지구단위계획, 도시계획시설 저촉, 상업지 용적률 상한(창원시 조례 기준 확인)
- [ ] 교통영향평가·건축심의 대상 여부, 대형점(유통산업발전법) 등록·입지 제한
- [ ] 주변 학교 인접 → 학교환경위생정화구역(숙박·유흥 용도 제한) 해당 여부
- [ ] 아파트 일조권 침해 → 신축 높이 제한(북측 이격), 민원 가능성

## D. 시장·수요 (현장 시장조사)
- [ ] 상권 실제 유동인구: 평일/주말, 낮/저녁 각 15분 카운트 (시각 기록)
- [ ] 인근 상가 **공실률**(1층 임대 현수막 개수), 임대료 호가 → 중개업소 3곳 이상 청취(이름/시각 기록)
- [ ] 인근 신축·분양 중 현장(경쟁 공급): 분양가, 계약률(분양사무소 청취), 미분양 여부
- [ ] 인근 대형 유통·복합몰 영향(경쟁 및 상권 이동 여부)
- [ ] 구도심 쇠퇴 징후: 폐업 점포, 노후 건물 비율, 거주 인구 연령
- [ ] 아파트 시세: 인근 단지 호가 vs 실거래(국토부 실거래로 별도 대조)

## E. 사업성 직결 현장 확인
- [ ] 도로 폭·진출입 동선, 주차 진입 가능성, 대중교통(버스정류장·역) 거리
- [ ] 지반/지형 고저차, 침수 흔적(창원 마산권 해안 인접 시 확인)
- [ ] 철거·공사 시 인접(아파트·학교) 민원 요소 — 공사차량 동선
- [ ] 공사비/분양가 가정에 쓸 인근 최근 사례 확보

## F. 사진 촬영 목록 (증빙\ 폴더 저장, 파일명에 방향·시각)
부지 4방향 전경 / 분할선 예상 위치 / 공용 출입구·주차 램프 / 도로 접면 / 인근 공실 상가 / 경쟁 현장 / 분양사무소 가격표 / 건물 외벽 균열·노후

## G. 제안자 전달용 정리 형식 (귀국 후)
