# 대동백화점 부지 분할 검토 — 다른 PC에서 이어하기 (2026-11-12 작성)

## 현재 상태
- 보고서 3종 완성: 요약10장 / 보고용 큰글씨 26장 / 통합보고서 37장 (PPT + PDF). 회사명은 **대원홀딩스**.
- 회신 문안(제안서 거절) 장은 구두로 하기로 해서 뺐음.
- 이미 발송한 이메일(nadriboy@naver.com)의 첨부는 "대한홀딩스" 표기가 있던 이전 버전 → 필요 시 재발송.

## 폴더 구조
- `대동백화점_부지분할_검토보고_*.pptx/.pdf` : 최신 3종 (이전 버전 pptx는 참고용)
- `*.md` : 리스크 검증메모, 조합진행·허가조건·용적률·분필 검토, 증빙자료 정리, 현장조사 체크리스트, 법령발췌
- `증빙\ev\crops, crops2, field` : 슬라이드에 들어간 증빙 이미지(빨간 박스)
- `증빙\법령` : 법령 원문 캡처(주택법·시행령·별표 4·별표 3·국토계획법 제52조)
- `실거래` : 성산구 아파트 실거래 원자료 csv + 요약 xlsx + summary84.json
- `작업도구` : 보고서를 다시 만드는 스크립트

## 보고서 다시 만들기 (python-pptx, pillow, PyMuPDF, openpyxl 필요)
```
set DAEDONG_ROOT=<이 폴더의 경로>      (경로가 C:\Users\cho\land\창원_대동백화점 이면 생략)
python 작업도구\build_report4.py report     # 보고용 큰글씨
python 작업도구\build_report4.py full       # 통합보고서(목차+부록)
python 작업도구\make_summary10.py           # 요약 10장
```
- PDF는 PowerPoint(COM) 또는 "PDF로 저장"으로 변환. 윈도우 한글 폰트 필요(맑은 고딕, 바탕).
- 실거래 재조회: `작업도구\apt_trade.py 48123 YYYYMM YYYYMM 출력.csv` — 환경변수 `DATA_GO_KR_KEY`(공공데이터포털 인증키, 파일에 적지 않음) 필요. 아파트 매매 실거래가 자료 API 활용신청이 승인된 키여야 함. 엔드포인트는 `RTMSDataSvcAptTrade`.
- `make_crops*.py`는 원본 PDF(카카오톡 받은 파일, 다운로드 폴더)가 있어야 증빙 이미지를 다시 만든다. 이미 만든 이미지는 `증빙\ev`에 있으므로 보통 불필요.
